# ⚡ Realtime Chats: Long Polling, EventSource и WebSocket

## 📝 Краткое описание

3 мини чата реализованных с помощью longpolling, eventsource и webSocket.

## 🛠️ Использованные технологии

### Backend (`/server`)
- **Node.js** — среда выполнения
- **Express** — веб-фреймворк
- **ws** — библиотека для WebSocket
- **EventEmitter** — встроенный модуль для событий

### Frontend (`/client`)
- **React** — библиотека для UI
- **Axios** — HTTP-запросы
- **EventSource API** — нативный клиент для SSE
- **WebSocket API** — нативный клиент для WebSocket
